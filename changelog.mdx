## [1.0.2] - 2026-01-30

### Added

- Added anchor link support to Steps component with `id` and `noAnchor` props ([#187](https://github.com/mintlify/components/pull/187))
- Added `side` and `align` props to Tooltip component for positioning control ([#181](https://github.com/mintlify/components/pull/181) by [@shadabiiitnr20](https://github.com/shadabiiitnr20))

### Fixed

- Fixed `isMounted` check for View component ([#186](https://github.com/mintlify/components/pull/186))
- Fixed Mermaid duplicated IDs and gantt chart default sizing ([#183](https://github.com/mintlify/components/pull/183))

### Changed

- Updated internal props for Accordion and Card components ([#185](https://github.com/mintlify/components/pull/185))
- Prefer canonical Tailwind classes ([#178](https://github.com/mintlify/components/pull/178) by [@0xa3k5](https://github.com/0xa3k5))

<Tip>
  The Steps component now supports anchor links, making it easier to link directly to specific steps in your documentation.
</Tip>

## [1.0.1] - 2025-01-26

### Fixed

- Fixed CSS bundling by adding `@tailwindcss/cli` dependency ([#174](https://github.com/mintlify/components/pull/174))
- Fixed code block header truncation ([#173](https://github.com/mintlify/components/pull/173))
- Fixed type exports and disabled default `rollupTypes` ([#176](https://github.com/mintlify/components/pull/176))

### Changed

- Updated README with style override instructions ([#175](https://github.com/mintlify/components/pull/175))
- Updated `lodash` from 4.17.21 to 4.17.23 ([#171](https://github.com/mintlify/components/pull/171))

<Warning>
  This release fixes critical CSS bundling issues. If you experienced styling problems with v1.0.0, please upgrade to this version.
</Warning>

### Key Features

<AccordionGroup>
  <Accordion title="React 18 & 19 Support">
    Full compatibility with both React 18 and React 19, allowing you to use these components in any modern React application.
  </Accordion>
  
  <Accordion title="Tailwind CSS v3 & v4">
    Works seamlessly with both major versions of Tailwind CSS, with proper theme customization support.
  </Accordion>
  
  <Accordion title="TypeScript First">
    Built with TypeScript from the ground up, with full type definitions exported for all components.
  </Accordion>
  
  <Accordion title="Dark Mode">
    All components support light and dark themes out of the box.
  </Accordion>
  
  <Accordion title="Accessible">
    Components follow accessibility best practices with proper ARIA attributes and keyboard navigation.
  </Accordion>
</AccordionGroup>
